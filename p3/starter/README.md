# P3 starter: evidence templates

The runnable starting code is the W3.10 reference starter (`../../../labs/w3-10/starter`), copied to
`labs/w3-10/project/game` as described in `../README.md`. This folder holds the short records the project
asks you to keep. Copy them into your project branch (for example `project/game/evidence/`).

| File | Purpose |
|---|---|
| `evidence.md` | Milestone checkpoints, commands and actual results |
| `evaluation-record.md` | Four or more representative advice cases: legal versus useful, recorded separately |
| `browser-checks.md` | Real-browser observations: loading, unavailable server, stale state |
| `review-record.md` | Local PR / review record |
| `assistance-record.md` | Prompt or request summary and generated-change inspection (only if assistance was used) |
